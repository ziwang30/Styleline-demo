## 📖 About the Project

StyleLine is an educational web application designed to assess and give structured feedback on students' programming style. It analyzes code from multiple dimensions and presents feedback aligned with pedagogical goals.

The tool supports:
- Code feature extraction and classification
- Structured, modular feedback presentation
- Alignment with learning theory to support novice programmers

More information will be available upon official publication.
